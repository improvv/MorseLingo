# MorseLingo

눈 깜빡임으로 한글 모스부호를 연습하는 CV 학습 프로젝트입니다.
장기 목표는 듀오링고처럼 단계별로 학습하는 서비스이며, 현재는 **macOS에서 실행하는 Python 웹캠 프로토타입**입니다.

## 현재 구현 기능

- OpenCV로 웹캠 영상을 읽고 MediaPipe Face Landmarker로 눈 주변 좌표를 추정합니다.
- 양쪽 눈의 EAR을 계산해 감김 상태와 지속 시간을 측정합니다.
- 터미널에서 한글 문장을 받아 자모별 모스부호로 변환합니다.
- 검은 상단 패널에 흰 글씨로 문장과 목표 부호를 보여줍니다.
- 목표 바로 아래에 실제 입력을 정렬해 보여주고, 일치 여부를 초록색·빨간색으로 구분합니다.
- 입력 개수, 처음부터 일치한 부호 개수, 목표 기준 완료한 글자를 표시합니다.
- 긴 부호열은 현재 입력 위치에 맞춰 자동으로 페이지를 전환합니다.
- 삭제·초기화·제출·새 문장 입력을 지원합니다.

## 동작 원리

```text
웹캠 프레임
  → BGR을 RGB로 변환
  → 얼굴·눈 랜드마크 추정
  → EAR 계산
  → 눈 감김 시작·종료 추적
  → 감은 시간을 점·선으로 변환
  → 목표 부호열과 비교
  → 화면 피드백
```

### EAR과 시간 기준

EAR은 두 곳에서 측정한 눈꺼풀 세로 간격의 평균을 눈의 가로 길이로 나눈 값입니다.
정규화된 랜드마크 좌표는 영상 너비·높이를 곱해 픽셀 좌표로 바꾼 후 거리를 계산합니다.

| 항목 | 현재 기준 |
| --- | --- |
| 양눈 감김 | 양쪽 EAR 모두 `0.15` 미만 |
| 점 `.` | 감은 시간 `300ms` 미만 |
| 선 `-` | 감은 시간 `300ms` 이상 |
| 예: `342ms` | 선 `-` |

시간은 프레임 수가 아니라 단조 증가 시계로 측정합니다. 추적 유실·EAR 계산 실패·1초 초과 프레임 공백 시 진행 중 측정을 취소합니다. 초기화 후에는 눈을 뜬 상태부터 다시 시작합니다.

이 기준은 개발 중 관찰한 값으로 정한 **실험용 설정**이며, 사용자별 보정이나 표준 모스 리듬 평가를 완료한 것이 아닙니다.

## 개발 환경

- macOS, 카메라가 있는 컴퓨터
- Python 3.11 / Conda 환경 `morselingo`
- MediaPipe `0.10.35`
- OpenCV 패키지 `5.0.0.93` (`cv2.__version__`은 `5.0.0`)
- NumPy `2.4.6`, Pillow `12.3.0`

현재 Mac 환경에서는 MediaPipe 1.0.1로 모델 초기화 시 `DrishtiMetalHelper` 관련 강제 종료가 발생했고, 0.10.35로 변경한 뒤 동작을 확인했습니다. 모든 환경에서 동일한 오류가 발생한다는 의미는 아닙니다.

## 설치 및 실행

### 1. 환경 준비

새 환경이 필요한 경우:

```bash
conda create -n morselingo python=3.11 pip
conda activate morselingo
python -m pip install -r requirements.txt
```

이미 동작하는 `morselingo` 환경이 있다면 새로 만들거나 재설치하지 말고 활성화해서 사용하세요.
의존성 목록은 현재 환경에서 확인한 버전을 기록한 것이며, 별도의 깨끗한 환경에서 재설치 검증을 한 것은 아닙니다.
OpenCV 배포 패키지는 같은 `cv2` 모듈을 제공하므로 `opencv-python`과 `opencv-contrib-python`을 함께 설치하지 않는 구성을 사용합니다. 이 목록은 contrib 패키지 하나를 지정합니다.

### 2. 모델 다운로드

[Google의 Face Landmarker 안내](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker)에서 모델을 받거나 다음 명령을 실행하세요.

```bash
mkdir -p models
curl --fail --location \
  'https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task' \
  --output models/face_landmarker.task
```

`.task`는 직접 작성하는 코드가 아니라 학습된 모델 파일입니다. 모델은 Git에 포함하지 않습니다. 모델의 이용 조건은 원 제공처에서 확인하세요.

### 3. 프로그램 시작

프로젝트 폴더의 터미널에서 실행합니다.

```bash
conda activate morselingo
python landmark_test.py
```

1. 터미널에 `안녕하세요` 같은 한글 문장을 입력하고 Enter를 누릅니다.
2. 카메라 권한을 요청하면 사용하는 앱에 허용합니다.
3. 영상 창을 클릭하고 **영문 입력 상태**에서 `b`로 시작합니다.
4. 짧게·길게 눈을 감았다 떠서 점·선을 입력합니다.
5. `s`로 제출하고 결과를 확인합니다.

터미널의 문장 입력 단계에서는 `/q`로 종료할 수 있습니다. 현재는 한글·공백을 최대 100자까지 지원하며, 숫자·영문·문장부호는 재입력을 안내합니다.

### 조작 키

| 키 | 기능 |
| --- | --- |
| `b` | 입력 시작 또는 삭제 후 이어 입력 |
| `s` | 현재 부호열 제출 |
| `x` | 마지막 부호 하나 삭제 후 일시정지. `b`로 재개 |
| `c` | 같은 문장 초기화 후 준비 상태로 돌아가기 |
| `n` | 카메라와 창을 닫고 터미널에서 새 문장 입력 |
| `q` | 종료 |

입력 상태는 `READY → INPUT → REVIEW/RESULT`로 진행합니다. 삭제하면 `PAUSED`가 됩니다.
입력 중에만 부호를 저장하며, 목표 길이에 도달하면 `REVIEW`에서 자동으로 입력을 멈추고 제출을 기다립니다.

## 한글 변환 규칙

- 사용자가 제공한 한글 부호표 이미지를 데이터로 옮겼습니다. 독립적인 표준 검증을 완료한 표는 아닙니다.
- 완성형 한글을 초성·중성·종성으로 분해한 뒤 자모별 부호를 이어 붙입니다.
- 자모는 공백, 글자는 `/`, 단어는 `//`로 구분해서 표시합니다.
- 표에 있는 `ㅐ·ㅔ·ㅚ·ㅟ·ㅢ`는 해당 부호를 사용합니다.
- 표에 없는 쌍자음·겹받침·일부 복합모음은 구성 자모로 나누는 앱 확장 규칙을 사용합니다.
- 눈으로 구분자를 입력하지 않으며, 채점은 점·선 순서만 비교합니다.
- 화면의 완료된 글자는 **목표 문장의 경계에 맞춘 진행 안내**입니다. 자유 입력 부호열을 독립적으로 한글로 해독하는 기능은 아닙니다.

세부 확장 규칙은 [문장 연습 모드 설명](SENTENCE_MODE.md)과 `morse.py`를 참고하세요.

## 알려진 한계

- 자연 깜빡임과 의도적인 짧은 입력을 아직 구분하지 못합니다.
- 고정 EAR·시간 임계값은 조명·안경·카메라 각도·사용자에 영향을 받습니다.
- 눈 상태 흔들림을 줄이는 히스테리시스·디바운싱은 아직 적용하지 않았습니다.
- `OPEN` 표시는 양눈 감김 조건을 만족하지 않는다는 의미로, 한쪽 눈만 감은 경우도 포함됩니다.
- 한글 렌더링은 macOS의 `/System/Library/Fonts/AppleSDGothicNeo.ttc`에 의존합니다. 다른 OS에서는 글꼴 경로 수정이 필요합니다.
- `VideoCapture(0)`은 첫 카메라를 의미하며 반드시 내장 카메라는 아닙니다. iPhone 연속성 카메라가 선택되면 장치 설정을 확인하세요.
- 웹 서비스·로그인·진도 영구 저장·단계별 한글 교육 콘텐츠는 아직 구현하지 않았습니다.
- 카메라 영상은 로컬에서 처리하며, 현재 코드에는 영상 저장·서버 업로드 기능이 없습니다.

## 확인한 사항

- 사용자 환경에서 카메라 표시, 얼굴 랜드마크, EAR, 감김 시간, 점·선 입력 동작 확인
- 문장 기능 개발 중 완성형 한글 11,172개 변환과 입력 검증·진행률 계산 확인
- 카메라를 켜지 않고 합성 영상으로 한글 패널 렌더링 확인
- `299ms → .`, `300ms → -`, `342ms → -` 경계값 확인

위 확인은 자동화된 전체 회귀 테스트나 모든 환경의 실시간 정확도 보장이 아닙니다.
